JWT Token Decoder

Paste an access or ID token from a log, a phishing kit or an incident. The header and claims are decoded and explained, with extra detail for Microsoft Entra ID: which tenant and app, whether MFA was used, which admin roles and permissions the token carries, and the IP it was issued to.

● Runs in your browser. The token is never sent anywhere and is cleared when you leave the page.

What it explains

Who and what

User, tenant, the client app that requested the token (Microsoft first-party apps are named) and the API it is for, plus the IP address at sign-in with one-click lookups.

Red flags

No MFA in the amr claim, public command-line clients often abused in device-code phishing, privileged directory roles in wids, powerful scopes such as Mail.Send or Directory.ReadWrite.All, unusually long lifetimes and unsigned (alg none) tokens.

Honest limits

The signature is not verified, because that needs the issuer keys and a network call. Decoding shows what the token claims, which is exactly what an analyst needs to scope a stolen-token incident.
