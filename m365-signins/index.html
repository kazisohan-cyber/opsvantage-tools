What it looks for

Account takeover

Impossible travel between countries, successful sign-ins from countries outside your normal footprint, risky sign-ins flagged by Entra ID Protection.

Credential attacks

Password spraying across many users, brute force on one user, smart lockouts, and repeated MFA failures that suggest push bombing.

Weak paths in

Legacy authentication (IMAP, POP, SMTP, ActiveSync), sign-ins with no MFA, device code flow, ROPC and scripted user agents like python-requests.
