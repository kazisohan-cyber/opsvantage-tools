IOC Triage: a verdict on every indicator

A free browser extension for Chrome and Edge. Paste an alert, or click an IP, domain, URL, hash or CVE on any page, and get a verdict with the evidence behind it and what to do next. Then copy a ready ticket note.

What problem it solves

A single alert can hold five or six indicators. Checking them the usual way means a tab per indicator per intel site, then writing up what you found by hand. IOC Triage does the lookups in parallel, weighs what the sources say and writes the result in plain words, so the time goes on the decision instead of the copying.

How to use it

  1. Add it to Chrome or Edge from the Chrome Web Store. It works straight away; free API keys for VirusTotal, AbuseIPDB and abuse.ch add more sources and can be set later under Settings.
  2. Click an indicator or paste an alert. On SOC consoles and ticket systems, indicators are underlined; click one for a quick verdict. Or select text and right-click Investigate, or paste the whole alert into the side panel. Defanged values such as hxxps:// and 1.2.3[.]4 are fine.
  3. Read the verdict and act. Each indicator shows malicious, suspicious, benign, unknown or internal, with a confidence level, the reasons and what to do next. The alert gets a suggestion to escalate or close.
  4. Copy the ticket note into HaloPSA or any other ticket system, with formatting kept, or as Markdown. There is also an escalation note for L2 and a defanged IOC list.

Private by design

There is no OpsVantage server and no account. Requests go straight from your browser to each intel source with only the indicator, never the page or the alert text. API keys, client notes and history are stored in the browser. The full source is on GitHub, so you can check every request it makes.

FAQ

Is IOC Triage free?

Yes. The extension is free and open source under the Apache 2.0 licence, with no account. Some intel sources need a free API key of your own, such as VirusTotal and AbuseIPDB; the rest work without one.

What data leaves my browser?

Only the indicator you are checking, sent straight from your browser to each intel source. Your pasted alert, page content and API keys stay in the browser, and there is no OpsVantage server in between.

Does it work in Microsoft Edge?

Yes. Install it from the Chrome Web Store in Edge (allow extensions from other stores when Edge asks). It can also be force-installed with Intune or Group Policy.

Which intel sources does it use?

Without a key: GreyNoise community, Shodan InternetDB, ipinfo, RDAP domain age, DNS, CISA KEV, FIRST EPSS and NVD, plus its own lookalike and brand analysis. With a free key: VirusTotal, AbuseIPDB, abuse.ch (URLhaus, ThreatFox, MalwareBazaar) and urlscan.io.

Can it suggest whether to close an alert?

It suggests Escalate, Investigate first, Close or Needs more information, with the reasons, and never suggests closing when a lookup failed or an indicator is unknown. The decision is yours and goes on the ticket note.
