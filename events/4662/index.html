Event ID 4662: operation performed on an ad object

What Event ID 4662 (operation performed on an ad object) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Security · Severity: Informational · MITRE ATT&CK T1003.006 · Updated 2026-11-03

Event ID 4662 records an operation on an Active Directory object. It is very noisy in general, but one pattern makes it essential: the replication rights used by DCSync. When an account that isn't a domain controller uses those rights on the domain object, someone is pulling password hashes from AD.

The fields that matter

FieldWhat it tells you
Subject > Account NameWho performed the operation. DCs appear as their computer accounts.
Object TypedomainDNS ({19195a5b-6da0-11d0-afd3-00c04fd930c9}) for the domain object.
AccessesControl Access for extended rights.
PropertiesThe GUIDs of the rights used. 1131f6aa-9c07-11d1-f79f-00c04fc2dcd2 and 1131f6ad-9c07-11d1-f79f-00c04fc2dcd2 (Replicating Directory Changes and Changes All) are the DCSync ones; 89e95b76-444d-4c62-991a-0facbeda640c is Changes In Filtered Set.

What is normal

Domain controller computer accounts using the replication rights, and Entra Connect (Azure AD Connect) accounts that need them for password hash sync.

When Event ID 4662 is suspicious

  • Replication GUIDs used by a user account or a computer that is not a DC or the Entra Connect server.
  • Replication requests from a workstation IP (check the matching 4624).

Common false positive: The Entra Connect sync account (MSOL_... or Sync_...) legitimately replicates. Exclude it by name, and make sure only it has the right.

Find Event ID 4662 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4662; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

SecurityEvent
| where TimeGenerated > ago(7d) and EventID == 4662
| project TimeGenerated, Computer, Account, Activity, EventData
| order by TimeGenerated desc

FAQ

Which audit settings log DCSync in 4662?

Audit Directory Service Access must be on for domain controllers, and the domain object needs a SACL auditing the replication extended rights for Everyone.

What should I do if I see DCSync from an unexpected account?

Treat the domain as compromised: the attacker may have every password hash, including krbtgt. Disable the account, investigate, and plan a double krbtgt reset.
