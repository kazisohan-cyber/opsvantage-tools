Event ID 4657: registry value modified

What Event ID 4657 (registry value modified) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Security · Severity: Low · MITRE ATT&CK T1112 · Updated 2026-11-03

Event ID 4657 records a change to a registry value, but only for keys with registry auditing (a SACL) configured. Put that auditing on the handful of keys attackers love, such as Run keys, Image File Execution Options and Defender settings, and 4657 shows persistence and tampering the moment it happens, with old and new values.

The fields that matter

FieldWhat it tells you
Subject > Account NameWho changed it.
Object NameThe key, for example \REGISTRY\MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run.
Object Value NameThe value that changed.
Operation TypeNew value created, existing value modified, or deleted.
Old Value / New ValueBefore and after. The new value of a Run key is the program that will start.
Process NameWhat made the change.

What is normal

Software installers adding their own Run entries, Group Policy writing policy keys.

When Event ID 4657 is suspicious

  • New Run or RunOnce values pointing into AppData, Temp, ProgramData or Users\Public.
  • Values added under Image File Execution Options (debugger hijacking) or Winlogon.
  • Changes to Defender exclusion or LSA keys by anything other than your management tools.

Common false positive: Updaters for browsers and collaboration apps rewrite their Run entries often. Learn their paths.

Find Event ID 4657 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4657; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

SecurityEvent
| where TimeGenerated > ago(7d) and EventID == 4657
| project TimeGenerated, Computer, Account, Activity, EventData
| order by TimeGenerated desc

FAQ

Is Sysmon event 13 better than 4657?

Sysmon 13 needs no SACLs and covers any key in its configuration, so it is easier to deploy widely. 4657 is built in and works where Sysmon isn't installed.
