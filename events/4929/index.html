Event ID 4929: ad replica source naming context removed

What Event ID 4929 (ad replica source naming context removed) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Security · Severity: Low · MITRE ATT&CK T1207 · Updated 2026-11-03

Event ID 4929 is the partner of 4928: a domain controller stopped replicating a naming context from a source. Normal when a DC is demoted or the replication topology changes. In a DCShadow attack the rogue DC is added as a source, pushes its changes and is removed again, so 4928 and 4929 for the same unfamiliar source a few minutes apart is the pattern to look for.

The fields that matter

FieldWhat it tells you
Destination DRAThe DC that recorded the removal.
Source DRAThe partner that was removed. Compare with your DC list.
Source AddressDNS or GUID-based address of the source.
Naming ContextThe directory partition concerned.
Options / Status CodeReplication options and the result; 0 is success.

What is normal

Removals during DC demotion, decommissioning or site link changes, matching a change ticket.

When Event ID 4929 is suspicious

  • A 4929 for a source that never was a domain controller.
  • A 4928 and 4929 pair for the same source within a short window, with directory changes (5136) in between.

Common false positive: Demoting or replacing domain controllers produces 4929 on every remaining DC.

Find Event ID 4929 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4929; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

SecurityEvent
| where TimeGenerated > ago(7d) and EventID == 4929
| project TimeGenerated, Computer, Account, Activity, EventData
| order by TimeGenerated desc

FAQ

Do I need both 4928 and 4929 to detect DCShadow?

Either is a good signal on its own if the source is not a real DC. Seeing both, close together, is close to conclusive.
