Event ID 4741: computer account created

What Event ID 4741 (computer account created) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Security · Severity: Medium · MITRE ATT&CK T1136.002 · Updated 2026-11-03

Event ID 4741 is written on a domain controller when a computer account is created. Most come from domain joins by IT or provisioning tools. The catch is that, by default, any authenticated user can create up to ten computer accounts (the MachineAccountQuota setting), and several privilege escalation techniques, including resource-based constrained delegation abuse and noPac, begin by doing exactly that.

The fields that matter

FieldWhat it tells you
Subject > Account NameWho created the account. A normal user here is the main red flag.
New Computer Account > Account NameThe new computer name, ending in $.
SAM Account Name / DNS Host NameNames set at creation.
Service Principal NamesSPNs registered for the new account.
User Account ControlFlags set on the account.

What is normal

Computer accounts created by your join or deployment accounts, Intune or Autopilot connectors and administrators, with names that follow your naming standard.

When Event ID 4741 is suspicious

  • A computer account created by an ordinary user account.
  • Names that don't fit your convention, such as random strings or names copied from a DC.
  • A 4741 followed by a 4742 changing delegation settings, or by Kerberos tickets requested for the new account.

Common false positive: Self-service domain joins in small offices where users join their own laptops. Set MachineAccountQuota to 0 and delegate joins to a specific group to remove the noise and the risk.

Find Event ID 4741 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4741; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

SecurityEvent
| where TimeGenerated > ago(7d) and EventID == 4741
| project TimeGenerated, Computer, Account, Activity, EventData
| order by TimeGenerated desc

FAQ

How do I stop normal users creating computer accounts?

Set ms-DS-MachineAccountQuota on the domain object to 0 and grant the right to join computers to a dedicated group or OU instead.

Why do attackers create computer accounts?

A computer account they control has a password they know and can be given an SPN, which is what attacks such as resource-based constrained delegation and noPac need.
