Event ID 4776: ntlm credential validation

What Event ID 4776 (ntlm credential validation) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Security · Severity: Informational · MITRE ATT&CK T1550.002 · Updated 2026-11-03

Event ID 4776 is written when a domain controller (or a local machine, for local accounts) validates an NTLM credential. It shows NTLM failures that never appear as 4771, and it is the starting point for finding where NTLM is still used.

The fields that matter

FieldWhat it tells you
Logon AccountThe account being validated.
Source WorkstationThe name the client sent. It can be spoofed and is sometimes blank.
Error Code0x0 success, 0xC000006A wrong password, 0xC0000064 no such user, 0xC0000234 locked, 0xC0000072 disabled.

What is normal

Successful validations from known workstations and from applications that only support NTLM.

When Event ID 4776 is suspicious

  • Many accounts failing from one source workstation: password spraying over NTLM.
  • Workstation names that are not in your domain, or random-looking names.
  • NTLM use by admin accounts where Kerberos should be used.

Common false positive: Older apps, printers and scanners use NTLM legitimately. Record them before you start blocking NTLM.

Find Event ID 4776 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4776; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

SecurityEvent
| where TimeGenerated > ago(7d) and EventID == 4776
| project TimeGenerated, Computer, Account, Activity, EventData
| order by TimeGenerated desc

FAQ

Where do I see the source IP for NTLM failures?

4776 has only the workstation name. The matching 4625 on the server the user connected to has the source address.

Can 4776 help me turn off NTLM?

Yes. Successful 4776 events list which accounts and workstations still use NTLM, which is the inventory you need before restricting it.
