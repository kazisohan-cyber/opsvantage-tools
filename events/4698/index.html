Event ID 4698: scheduled task created

What Event ID 4698 (scheduled task created) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Security · Severity: Medium · MITRE ATT&CK T1053.005 · Updated 2026-11-03

Event ID 4698 is written when a scheduled task is created. Tasks are one of the most common ways attackers stay on a machine after a reboot, and the event includes the full task definition, so you can see exactly what will run.

The fields that matter

FieldWhat it tells you
Task NamePath and name, such as \Microsoft\Windows\UpdateCheck.
Task ContentThe task XML: look at Command, Arguments, the triggers and the account it runs as.
SubjectThe account that created it.

What is normal

Updaters for browsers, Office, OneDrive and drivers, and tasks created by your own management tools.

When Event ID 4698 is suspicious

  • A command in AppData, Temp, ProgramData or Users\Public.
  • Arguments with powershell -enc, cmd /c, mshta or a URL.
  • Names that imitate Microsoft tasks but sit outside the usual folders, or random names.
  • Tasks that run as SYSTEM created by a normal user account, or created remotely.

Common false positive: Software installs create tasks too. Check the publisher of the target file before raising it.

Find Event ID 4698 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4698; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

SecurityEvent
| where TimeGenerated > ago(7d) and EventID == 4698
| project TimeGenerated, Computer, Account, Activity, EventData
| order by TimeGenerated desc

FAQ

Why don't I see 4698 events?

"Audit Other Object Access Events" must be enabled (Advanced Audit Policy > Object Access). Without it Windows does not log task creation in the Security log.

What are 4699 and 4702?

4699 is a task deleted and 4702 a task updated. Attackers sometimes modify an existing task instead of creating one, so watch 4702 too.
