Windows security event IDs: the cheat sheet

The 76 Windows, Sysmon, PowerShell and Defender event IDs that matter for security monitoring, what each one means and how worried to be. Linked IDs have a full page with fields, false positives and queries.

Updated 2026-11-03

Logon and accounts (Security log)

IDLogEventSeverityWhy it matters
4624SecuritySuccessful logonInformationalBaseline of who logged on, from where and how. Logon type tells the story: 2 interactive, 3 network, 10 RDP, 9 new credentials (runas /netonly, also seen with pass-the-hash).
4625SecurityFailed logonLowMany failures for one account means brute force; one source failing against many accounts means password spraying.
4634SecurityLogoffInformationalPairs with 4624 via Logon ID to measure session length.
4647SecurityUser-initiated logoffInformationalInteractive user logged off.
4648SecurityLogon with explicit credentialsLowrunas, scheduled tasks or lateral-movement tools using another account's credentials.
4672SecuritySpecial privileges assigned to new logonInformationalAn admin-equivalent logon. Useful to spot admin accounts used from unusual hosts.
4720SecurityUser account createdMediumAttackers create accounts for persistence.
4722SecurityUser account enabledLowRe-enabled dormant accounts are a persistence trick.
4723SecurityPassword change attemptInformationalUser changed their own password.
4724SecurityPassword reset by another accountMediumAn admin (or attacker) reset someone else's password, a common takeover step.
4725SecurityUser account disabledLowMass disabling can be sabotage or ransomware prep.
4726SecurityUser account deletedMediumCovering tracks or sabotage.
4728SecurityMember added to global security groupMediumPrivilege escalation when the group is Domain Admins or another admin group.
4732SecurityMember added to local security groupMediumAdding to local Administrators or Remote Desktop Users gives persistence.
4756SecurityMember added to universal security groupMediumEnterprise Admins / Schema Admins are universal groups.
4738SecurityUser account changedLowLook for "Don't require preauth" (AS-REP roasting) or password-never-expires being set.
4740SecurityAccount locked outLowBrute force, or an old password cached on a phone or mapped drive.
4767SecurityAccount unlockedInformationalHelpdesk or self-service unlock.
4765SecuritySID History added to an accountHighSID History injection gives hidden admin rights.
4766SecuritySID History add attempt failedHighSomeone tried SID History injection.
4794SecurityDSRM administrator password setHighThe DSRM account can be used as a domain controller backdoor.
4729SecurityMember removed from global security groupLowRemoving admins can lock defenders out; removing a just-added account can be cleanup.
4733SecurityMember removed from local security groupLowOften cleanup after temporary admin rights, sometimes an attacker covering tracks.
4741SecurityComputer account createdMediumAny user can add up to 10 computers by default (MachineAccountQuota); attacks like RBCD abuse and noPac start here.
4742SecurityComputer account changedLowDelegation settings, UserAccountControl and name changes on computer accounts enable privilege escalation.
4743SecurityComputer account deletedLowUsually cleanup of retired machines; deleting a computer account created for an attack removes evidence.
4800SecurityWorkstation lockedInformationalShows when a user stepped away; useful for building a timeline.
4801SecurityWorkstation unlockedInformationalShows the user was back at the keyboard.
4778SecuritySession reconnected to a window stationInformationalRDP reconnects record the client name and address, which a plain 4624 may not.
4779SecuritySession disconnected from a window stationInformationalMarks the end of an RDP session that was disconnected rather than logged off.

Kerberos / NTLM

IDLogEventSeverityWhy it matters
4768SecurityKerberos TGT requestedInformationalPre-auth type 0 means no pre-authentication (AS-REP roastable account).
4769SecurityKerberos service ticket requestedInformationalBursts of requests with encryption 0x17 (RC4) for service accounts are Kerberoasting.
4771SecurityKerberos pre-authentication failedLowThe Kerberos version of a failed logon: brute force or spraying against a DC.
4776SecurityNTLM credential validationInformationalError 0xC000006A in bulk is NTLM brute force; NTLM where Kerberos is expected can mean pass-the-hash.

Policy, logs and tampering

IDLogEventSeverityWhy it matters
1102SecuritySecurity audit log clearedCriticalAttackers clear the Security log to hide what they did. Almost never legitimate on servers.
104SystemEvent log clearedHighA System or application log was cleared.
4719SecuritySystem audit policy changedHighTurning off auditing blinds the SOC before an attack.
4739SecurityDomain policy changedMediumPassword or lockout policy weakened.
4662SecurityOperation performed on an AD objectInformationalWith the replication GUIDs (1131f6aa / 1131f6ad / 89e95b76) from a non-DC account, this is DCSync.
5136SecurityDirectory object modifiedLowGPO and AdminSDHolder changes show up here.
4928SecurityAD replica source naming context establishedLowNormal when DCs set up replication; a source that is not a known domain controller points to a rogue DC (DCShadow).
4929SecurityAD replica source naming context removedLowThe counterpart of 4928; DCShadow adds and then removes a fake replication partner.
1100SecurityEvent logging service shut downMediumNormal during a shutdown; on its own, without a reboot, someone stopped logging.
4616SecuritySystem time changedLowSmall corrections by the Windows Time service are normal; big jumps confuse timelines and can break Kerberos.
4663SecurityAttempt to access an objectInformationalWith file or registry auditing on, shows who read, wrote or deleted protected objects. Bursts point to ransomware or data theft.
4670SecurityPermissions on an object changedLowPermission changes on sensitive files or keys can grant an attacker access or prepare files for encryption.
4657SecurityRegistry value modifiedLowWith registry auditing on Run keys, LSA or Defender keys, shows persistence and tampering as it happens.

Processes, services, tasks

IDLogEventSeverityWhy it matters
4688SecurityNew process createdInformationalWith command-line auditing on, this shows encoded PowerShell, LOLBins and ransomware commands.
4697SecurityService installedMediumPsExec, Cobalt Strike and many RATs install a service.
7045SystemNew service installedMediumThe System-log version of a new service, often PsExec (PSEXESVC) or malware.
7040SystemService start type changedLowDisabling security services (Defender, backup agents) before ransomware.
7036SystemService state changedInformationalService started or stopped. Look for security or backup services stopping.
4698SecurityScheduled task createdMediumClassic persistence.
4699SecurityScheduled task deletedLowCleanup after a one-time task.
4702SecurityScheduled task updatedLowExisting task hijacked to run a new command.

Network and shares

IDLogEventSeverityWhy it matters
5140SecurityNetwork share accessedInformationalAccess to ADMIN$ or C$ from a workstation is lateral movement.
5145SecurityShare object access checkInformationalDetailed share access; PsExec writes to ADMIN$.
5156SecurityWindows Filtering Platform allowed a connectionInformationalNetwork connection log; noisy but useful for C2 hunting.

PowerShell

IDLogEventSeverityWhy it matters
4103PowerShellPowerShell module loggingInformationalPipeline execution details.
4104PowerShellPowerShell script block loggedLowThe decoded script that actually ran. Best single source for malicious PowerShell.

Defender

IDLogEventSeverityWhy it matters
1116DefenderDefender detected malwareHighMicrosoft Defender found a threat.
1117DefenderDefender took action on malwareMediumRemediation result for a detection.
5001DefenderDefender real-time protection disabledHighAttackers turn off Defender before running tools.
5007DefenderDefender configuration changedMediumExclusions added for a folder or process are a common bypass.

Sysmon

IDLogEventSeverityWhy it matters
1Sysmonprocess creationInformationalFull command line, hashes and parent process.
3Sysmonnetwork connectionInformationalWhich process talked to which IP and port.
7Sysmonimage loadedInformationalDLL side-loading hunts.
8SysmonCreateRemoteThreadMediumProcess injection.
10Sysmonprocess accessInformationalAccess to lsass.exe is credential dumping (Mimikatz, procdump).
11Sysmonfile createdInformationalDropped payloads and ransom notes.
12Sysmonregistry object added or deletedInformationalRun-key persistence.
13Sysmonregistry value setInformationalRun keys, services, Defender settings.
