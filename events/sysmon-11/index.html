Sysmon Event ID 11: file created

What Sysmon Event ID 11 (file created) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Microsoft-Windows-Sysmon/Operational · Severity: Informational · Updated 2026-11-03

Sysmon event ID 11 records a file being created or overwritten, with the process that did it. It is the best way to see payloads land: the script dropped into Temp, the executable written to a startup folder, the archive created before data leaves.

The fields that matter

FieldWhat it tells you
ImageThe process that created the file.
TargetFilenameThe full path of the new file.
CreationUtcTimeThe file's creation time; a time far in the past on a new file can mean timestomping.
UserThe account the process ran as.

What is normal

Installers, browsers saving downloads and Office writing temporary files.

When Sysmon Event ID 11 is suspicious

  • Executables, scripts or DLLs written to AppData, Temp, Users\Public, ProgramData or startup folders.
  • Office applications or browsers writing .exe, .dll, .js, .hta or .lnk files.
  • A process writing thousands of files with a new extension: ransomware.

Common false positive: Software updaters write executables to AppData all the time. Pair 11 with the file hash (Sysmon 15 or your EDR) before judging.

Find Sysmon Event ID 11 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Sysmon/Operational'; Id=11; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

Event
| where TimeGenerated > ago(7d) and Source == "Microsoft-Windows-Sysmon" and EventID == 11
| project TimeGenerated, Computer, RenderedDescription, EventData
| order by TimeGenerated desc
