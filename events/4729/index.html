Event ID 4729: member removed from global security group

What Event ID 4729 (member removed from global security group) means, the fields to check, what is normal and what is suspicious, with PowerShell and KQL queries to find it.

Log: Security · Severity: Low · MITRE ATT&CK T1531 · Updated 2026-11-03

Event ID 4729 records that a member was removed from a security-enabled global group, such as Domain Admins. On its own it is housekeeping. It becomes interesting next to a 4728 for the same account: temporary admin rights added and removed in a short window is a common attacker pattern, and removing legitimate admins can lock defenders out.

The fields that matter

FieldWhat it tells you
Member > Account NameWho was removed, often shown as a distinguished name.
Group > Group NameThe group.
Subject > Account NameWho removed them.

What is normal

Leavers removed from groups, and admin rights removed when a project ends.

When Event ID 4729 is suspicious

  • An account added (4728) and removed again within hours, especially outside working time.
  • Real admins removed from Domain Admins by an unexpected account.

Common false positive: Privileged access tools that grant just-in-time membership add and remove accounts constantly. Exclude their service account.

Find Event ID 4729 with PowerShell

Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4729; StartTime=(Get-Date).AddDays(-7)} -MaxEvents 50 |
  ForEach-Object {
    $d = [ordered]@{ Time = $_.TimeCreated; Computer = $_.MachineName }
    ([xml]$_.ToXml()).Event.EventData.Data | ForEach-Object { $d[$_.Name] = $_.'#text' }
    [pscustomobject]$d
  } | Format-List

Microsoft Sentinel (KQL)

SecurityEvent
| where TimeGenerated > ago(7d) and EventID == 4729
| project TimeGenerated, Computer, Account, Activity, EventData
| order by TimeGenerated desc

FAQ

What is the difference between 4729 and 4733?

4729 is a global group (most domain groups, including Domain Admins); 4733 is a local or domain local group, such as Administrators on a server.
