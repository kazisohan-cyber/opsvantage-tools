Tools / Changelog

What's new

Changes to the tools on this site, newest first. The IOC Triage browser extension has its own changelog on GitHub.

7 November 2026

Five new tools

  • Phishing Link Unwrapper: peels Safe Links, Proofpoint URL Defense (v1 to v3), Barracuda, Google and other redirects off a link without visiting it, then checks the real destination.
  • Hunting Query Generator: turns indicators into hunting queries for Microsoft Sentinel and Defender XDR (KQL), Splunk, CrowdStrike LogScale and Elastic.
  • CVE Prioritizer: ranks CVEs by CISA KEV, FIRST EPSS and CVSS into a patch-first list.
  • Payload Decoder: decodes encoded PowerShell, Base64, gzip, hex and more, layer by layer, and lists what the script does.
  • JWT Token Decoder: explains Entra ID and other tokens, including MFA, admin roles, scopes and the sign-in IP.

Also new

  • An embeddable DMARC checker for MSP and IT websites.
  • The source of this site is now public on GitHub.
  • The home page box recognises tokens, encoded payloads, CVE lists and links. The IOC Extractor can send its results to the Hunting Query Generator and the CVE Prioritizer.

6 November 2026

Easier to read

  • Charts in every tool: the route an email took with the delay at each hop, a DMARC grade gauge with the steps to p=reject, an SPF include tree with a lookup meter, an attack timeline and MITRE ATT&CK stages for Windows events, a world map and weekday-by-hour heatmap for sign-ins, and an indicator breakdown for the IOC Extractor.
  • A short demo video on each tool page, and preview images when a page is shared on LinkedIn, Slack or chat.
  • "Save PDF report" in every tool, with a report header and only the results on the page.
  • Three quick tips the first time you open a tool.
  • A How it works page: what each tool checks, how verdicts and scores are worked out, and the limits.

Easier to use

  • A "paste anything" box on the home page that recognises email headers, Windows events, Entra sign-in logs, domains and indicator lists, and opens the right tool.
  • "What to do now" steps at the top of every result.
  • Buttons to send results to the next tool, such as an email's indicators to the IOC Extractor.
  • Ctrl+Enter runs the analysis in every tool.

More capable

  • One-click lookups under every IP, domain, URL, hash and CVE: VirusTotal, AbuseIPDB, GreyNoise, Shodan, urlscan, crt.sh, MalwareBazaar, NVD, CISA KEV and others.
  • Email Header Analyzer reads a whole .eml: every link with its real destination (Safe Links unwrapped) and every attachment with its SHA-256. Brand impersonation from a domain that passes authentication is now at least suspicious.
  • Windows Event Triage accepts JSON and CSV exports from Microsoft Sentinel, Splunk and Elastic.
  • IOC Extractor finds file names and paths, registry keys, ASNs and Bitcoin addresses, and understands (at)-style defanged emails.

Accessibility and security

  • All pages pass automated WCAG 2.2 AA checks (axe-core) in both themes: stronger text contrast, visible keyboard focus, a skip link, underlined links in text and keyboard-scrollable code blocks.
  • A Content Security Policy on every page; no page runs inline scripts.

5 November 2026

  • M365 Posture Scanner: live sign-in enabled. Shared mailboxes and other unlicensed accounts no longer skew the MFA and stale-account figures, and free licences no longer show as thousands of unused seats.
  • Five new guides: new admin account detection, Kerberoasting, malicious inbox rules, legacy authentication and MFA fatigue.
