What it decodes

Logon status codes

NTSTATUS values from Event ID 4625 Status and Sub Status, 4776 Error Code and many sign-in logs: wrong password, unknown user, locked out, disabled, expired, outside logon hours, clock skew and the rest. Status 0xC000006D is generic, so the Sub Status is what tells you why.

Kerberos

Result and failure codes from Event IDs 4768, 4769 and 4771, in hex or decimal (24 is 0x18), plus the Ticket Options bit field from 4768 and 4769, so 0x40810010 becomes forwardable, renewable, canonicalize and renewable-ok.

Process access masks

The GrantedAccess value in Sysmon Event ID 10 split into its rights. Memory read access (PROCESS_VM_READ) to lsass.exe, such as 0x1010 or 0x1410, is the classic sign of a credential dumping tool.
