How it finds lookalikes

Variants

Missing, doubled, swapped and neighbouring-key letters, look-alike characters (rn for m, 0 for o, l for 1, vv for w), Cyrillic and Greek homoglyphs encoded as punycode, added hyphens and dots, common phishing keywords such as login, secure and invoice, and the same name under other top-level domains.

Live DNS check

Each variant is looked up over DNS-over-HTTPS. A name that exists in DNS is registered; for those, the tool reads the web address (A record), mail servers (MX), SPF and DMARC. A lookalike with MX records can receive replies and usually send mail as well.

Read the results

Not every registered lookalike is hostile: companies buy common typos to protect their brand, and some are parked. Check who owns it before acting, and add the dangerous ones to your mail and web blocklists. The tool checks up to about 400 variants per domain.
